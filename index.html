    📚 รายวิชาทั้งหมด

    📝 คะแนนสอบกลางภาค / ปลายภาค (ตั้งคะแนนเต็มเอง • 0 = ไม่ใช้)

    สองช่องนี้แยกจากหน่วยคะแนนเก็บ ไม่นำไปรวมในสัดส่วนของหน่วยด้านบน — ตอนคิดเกรดจะรวม คะแนนเก็บ + กลางภาค + ปลายภาค เทียบกับคะแนนเต็มรวมทั้งสามส่วน

    เพิ่มหน่วยและกด “บันทึกหน่วย” แล้วดาวน์โหลดฟอร์ม → กรอก → นำเข้า → ตรวจในตาราง → 💾 บันทึก (ช่องว่างในไฟล์ = ไม่เปลี่ยนค่าเดิม)
    เลือกรายวิชาเพื่อเริ่มบันทึกผลการเรียน

    ให้คะแนนรายตัวชี้วัด (ดีเยี่ยม=3 ดี=2 ผ่าน=1 ไม่ผ่าน=0) ระบบสรุประดับให้อัตโนมัติ • กรอกครบทุกส่วนแล้วกดบันทึกครั้งเดียว

    🔒 ห้องนี้ถูกล็อก (อนุมัติผลแล้ว) — แก้ไขไม่ได้ จนกว่าแอดมินจะปลดล็อก

    คุณลักษณะอันพึงประสงค์ 8 ประการ (หลักสูตรฯ 2551): 1.รักชาติ ศาสน์ กษัตริย์ • 2.ซื่อสัตย์สุจริต • 3.มีวินัย • 4.ใฝ่เรียนรู้ • 5.อยู่อย่างพอเพียง • 6.มุ่งมั่นในการทำงาน • 7.รักความเป็นไทย • 8.มีจิตสาธารณะ

    การอ่าน คิดวิเคราะห์ และเขียน (ผ่าน/ไม่ผ่าน)

    กิจกรรมพัฒนาผู้เรียน (ผ่าน/ไม่ผ่าน) + ชื่อชุมนุม + สมรรถนะสำคัญ (สรุปรวม — เติมให้อัตโนมัติจากแท็บสมรรถนะ 5 ประการ)

    สมรรถนะสำคัญของผู้เรียน 5 ประการ ตามหลักสูตรฯ 2551 — ประเมิน 4 ระดับ (ดีเยี่ยม/ดี/ผ่าน/ไม่ผ่าน) • ช่อง "สรุป" คิดจากระดับต่ำสุด และเติมลงช่องสมรรถนะรวมให้อัตโนมัติ

    เช็คครบทุกคาบ • เช็คบางคาบ • มีคาบแต่ยังไม่เช็ค • ไม่มีคาบสอน • เลขสีแดง = วันหยุด

    เลือกวันที่และคาบ แล้วกดโหลดรายชื่อ

    📍 ภาพรวมการมาเรียนรายวัน (ทั้งโรงเรียน)

    ⚠️ ระบบติดตามนักเรียนเสี่ยง (รายวิชา)

    เสี่ยงผลการเรียน = % สะสม ณ วันนี้ (คะแนนที่กรอกแล้ว ÷ เต็มของหน่วยที่กรอกแล้ว) ต่ำกว่าเกณฑ์ • เสี่ยง มส. = เวลาเรียนรายวิชา (มา+สาย ÷ คาบที่ต้องเรียนตามตารางสอน) ต่ำกว่า 80%

    👩‍🏫 สำหรับครู

    1. เข้าสู่ระบบ เลือกชื่อ + กรอก PIN (เปลี่ยน PIN ได้ที่ปุ่ม 🔑 มุมบน — แนะนำให้เปลี่ยนจาก 1234)
    2. เช็คชื่อ หน้าเสาธง = ครูประจำชั้น • รายคาบ = ครูที่สอนห้องนั้น
    3. บันทึกผลการเรียน เลือกภาคเรียน → วิชา → กรอกคะแนนรายหน่วย ระบบคำนวณเกรดตามตารางแปลงเกรด
    4. สมรรถนะ/คุณลักษณะ กรอกรายห้องตามภาคเรียน
    5. สอบแก้ตัว แก้เกรด 0/ร/มส/มผ
    6. ส่ง/อนุมัติผล เมื่อกรอกครบ กดส่งตรวจ → รองผอ./หัวหน้าวิชาการอนุมัติ/ล็อก (ห้องที่ล็อกแล้วแก้ไขไม่ได้) → ผู้อำนวยการอนุมัติรายห้อง (ขั้นที่ 2) • ปลดล็อก/ล็อกบังคับเป็นสิทธิ์แอดมิน

    👨‍👩‍👧 ผู้ปกครองตรวจผลการเรียน

    เปิดลิงก์ที่แอดมินแจก (หรือกดปุ่ม “ผู้ปกครอง” ที่หน้าเข้าสู่ระบบ) → กรอกเลขประจำตัว + วันเกิดนักเรียน (พ.ศ.) → ดูและพิมพ์ใบรายงานได้ ระบบแสดงเฉพาะห้องที่โรงเรียนอนุมัติผลแล้ว และกรอกผิดหลายครั้งจะถูกล็อกชั่วคราว

    🛠️ สำหรับแอดมิน

    • เริ่มใช้งานปีแรก: ตั้งค่าข้อมูลโรงเรียน/ปีการศึกษา → นำเข้ารายชื่อนักเรียน → นำเข้าตารางสอน (สร้างบัญชีครู PIN 1234 ให้อัตโนมัติ) → กำหนดครูประจำชั้นใน “จัดการครู / PIN”
    • จัดการครู/PIN: ช่อง PIN เว้นว่าง = ไม่เปลี่ยนรหัสเดิม (ระบบเก็บเป็นรหัสเข้ารหัส ดูย้อนหลังไม่ได้ — ลืมให้ตั้งใหม่)
    • ผู้ปกครอง & สิทธิ์เมนู: ตั้งค่าระบบ → 🔐 ผู้ปกครอง & สิทธิ์เมนู (เปิด/ปิดบริการ คัดลอกลิงก์ กำหนดเมนูของครู/รองผอ./ผอ.)
    • สุขภาพระบบ: แอดมิน → เผยแพร่/สำรอง ดูแถบเขียว/เหลือง/แดง (ใบอนุญาต, สำรองข้อมูล, ขนาดข้อมูล)
    • สิ้นปีการศึกษา: (1) จบภาค 2 และอนุมัติผลทุกห้อง (2) แก้ผลสอบแก้ตัวให้เสร็จ (3) แอดมิน → 🗓️ ขึ้นปีใหม่/คลังปี → ตรวจสอบ → พิมพ์ปีใหม่ยืนยัน → รอจนเสร็จ (ระหว่างนี้ผู้อื่นใช้ระบบไม่ได้ชั่วคราว) (4) นำเข้านักเรียน ม.1 ใหม่ + ตั้งครูประจำชั้น + นำเข้าตารางสอนใหม่ + ตั้งวันที่ภาคเรียน
    • ปีเก่าอยู่ที่ไหน: แท็บ “คลังปีการศึกษา” เป็นไฟล์ Google Sheets เต็มของแต่ละปี
    • ต่ออายุใบอนุญาตรายปี: ติดต่อครูรุ่งนิรันดร์ → แก้วันที่ใน Code.gs (LICENSE_EXPIRES) แล้ว Deploy → Manage deployments → ✏️ Edit “ตัวเดิม” → New version (ห้ามกด New deployment)
    • แก้ Code.gs ต้อง Deploy เวอร์ชันใหม่ / แก้ index.html ต้องอัปขึ้น Cloudflare Pages ใหม่
